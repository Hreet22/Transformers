# PowerPulse AI — Risk & Optimization Engine

## Overview
PowerPulse AI is a predictive smart-grid management system designed to reduce transformer overloads and prevent urban blackouts.

This module focuses on:
- Risk Score Calculation
- Transformer Overload Detection
- Automated Load Redistribution
- Optimization using PuLP

## Features
- AI-based risk scoring
- Load forecasting integration
- Optimization using Linear Programming
- Automated redistribution recommendations

## Technologies Used
- Python
- Pandas
- NumPy
- PuLP
- Matplotlib

## Workflow
Forecast Load → Risk Detection → Optimization → Load Redistribution
